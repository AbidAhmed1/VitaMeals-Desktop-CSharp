# VitaMeals — Desktop Management Application

## 🛍️ Overview
**VitaMeals Desktop** is a C# Windows Forms application built to handle hospital catering administration natively on desktop machines. It serves as the desktop management client within the VitaMeals ecosystem.

The project was developed as a Year-End Project (**PFA - Projet de Fin d'Études**) at **ESEN Manouba**.

## 🚀 Features
* 👨‍⚕️ **Doctor Interface** — Patient registration and diet prescription management (`InterfaceMedecin`, `AjouterPatient`).
* 🔐 **Admin Portal** — User roles, system permissions, and master data management (`InterfaceAdministrateur`, `DashboardAdmin`, `AjouterActeurs`).
* 🍳 **Kitchen Operations** — Real-time view of daily meals to prepare by ward (`InterfaceCuisinier`, `AjouterRepas`).

## 🛠️ Technologies
* **Language:** C#
* **Framework:** .NET Framework (Windows Forms / WinForms)
* **IDE:** Visual Studio
* **Database:** MySQL / SQL Server (`hopital.sql`)

## 🎯 Project Objective
To provide a fast, reliable desktop environment for hospital staff to manage meal preparations offline or on local networks.
